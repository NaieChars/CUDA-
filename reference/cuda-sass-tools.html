统一术语

术语含义
机器码硬件指令的二进制编码
汇编 / 反汇编低层操作的可读表示 / 将机器码转成可读指令文本
PTX虚拟指令集的中间表示；虚拟寄存器不等于硬件分配
SASS目标 GPU 实际机器指令的可读文本
cubin / fatbin设备代码对象 / 可容纳多种设备代码表示的容器
PC / 指令偏移指令位置 / 函数内的相对位置；不是耗时
谓词控制参与执行的条件；@P0 为真，@!P0 为假
依赖链一条指令产生的值被后续指令使用
静态指令数反汇编中所数的指令位置数
动态 warp 指令数运行时各 warp 执行指令的累计次数
pred-on 线程指令数参与执行、谓词为真的线程操作累计次数
warp sampling周期性采样 warp 状态并关联指令位置，不是逐条计时

来源：PTX ISA、Binary Utilities、NCU Profiling Guide。具体寄存器与计数对应由本项目 SASS 和旧报告验证。

最小阅读词表

LDS R28, [R27+0x400];    // 读 shared 的 32 bit 值到 R28
LDS.128 R8, [R0];        // 每参与线程读 16 字节 → R8..R11
STS [R26], R33;          // 写 shared，目的地址在前
LDG / STG               // global load / store 指令族
FFMA R8, R8, R28, R29;   // 新 R8 = 旧 R8×R28+R29
@!P0 BRA 0x2a0;          // P0 假时参与跳转
BAR.SYNC…               // 识别 block 同步；完整后缀按架构解释
MOV / IADD / ISETP      // 搬值 / 整数加 / 比较设谓词
RZ / UR                 // 零寄存器 / uniform 寄存器命名

0x10=16，0x40=64，0x400=1024；本例地址偏移按字节
一个 float=4 字节；LDS.128 中 128 的单位是 bit

R8 是每线程的寄存器操作数，不是整个 warp 的共享变量；相同 R 编号可以在不同阶段装不同值。完整 SASS 的编码和调度注记不等于 profiler 耗时。.reuse 是寄存器操作数复用相关标记，不能拿来证明某级内存缓存命中。

shared 版的计数公式

以下仅适用于本课这份 sm_120 SASS、block=16×16、BK=16、所有线程参与 tile 计算的实现。改代码或编译器后，重新检查指令体。

每线程每 K 段：
  A：4 条 LDS.128 → 16 个 float
  B：16 条 LDS    → 16 个 float
  load 指令合计：20；标量操作数合计：32

B = ceil(M/16) × ceil(N/16)       // block 数
W = 256/32 = 8                   // warp/block
Q = ceil(K/16)                   // K 段数

shared load 动态 warp 指令 = B×W×Q×20
FFMA 动态 warp 指令        = B×W×Q×16
FFMA pred-on 线程指令      = B×W×Q×16×32

完整 1024³：load=41,943,040；线程 FFMA=1,073,741,824
完整  512³：load= 5,242,880；线程 FFMA=  134,217,728
尾部 1023×1009×1031：load=42,598,400；线程 FFMA=1,090,519,040

512³ 和尾部数字是课堂预测，未新增采集验证。逻辑 GEMM 常用 FLOP 分子是 2MNK；尾部补零会使实际执行工作多于逻辑有效工作。

读取宽度 × 指令数 × lane 数得到的是逐 lane 的逻辑读取量，不能直接得到不同地址字节数、bank wavefront、缓存 sector 或 DRAM 字节。这些各自需要对应口径的观测。

证据与结论模板

问题：我预测哪一项工作会怎样变化？
版本：源码、exe、报告分别来自哪里，是否对应？
预测：公式、单位、参与条件。
观察：具体命令和原始值。
结论：已确认 / 有支持 / 待验证。
下一步：什么最小观测能区分剩下的解释？

静态 SASS 能确认生成了什么；动态计数能验证运行的工作量；普通计时判断整体时间；逐 PC 样本能提供定位线索，仍要分析依赖。采样热点可能位于消费结果的指令，不能凭热点宣布根因。

小收益：A/A 看测量波动，交错 A/B 或 AB/BA 看配对差值；进程内多次启动的均值不增加独立轮次数。区间跨零表示本批不足以稳定判断方向，不证明无效或等效。
