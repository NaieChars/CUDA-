符号与约定

符号含义
BblockDim.x；本项目为 [32,1024] 内 2 的幂
Iitems_per_thread；本项目为 [1,64]
局部和一个线程私有 sum 中的累加结果
部分和一个 block 输出到 partial[b] 的结果
一轮 / pass一次 kernel 启动，将输入归约成各 block 的部分和

三条索引关系

base = size_t(blockIdx.x) * B * I
idx  = base + tid + size_t(j) * B
下一轮长度 = n / (B*I) + (n % (B*I) != 0)

同一 j 时相邻 tid 访问相邻元素。每个有效输入恰好被一个线程读取；尾部不读取越界位置，线程局部和从 0 开始。shared memory 仍只需 B 个 float。

查看 reduce_multi_item
__global__ void reduce_multi_item(const float* in, float* partial,
                                  size_t n, int items_per_thread)
{
    extern __shared__ float s[];
    const unsigned int tid = threadIdx.x;
    const size_t base = static_cast<size_t>(blockIdx.x)
                      * blockDim.x * items_per_thread;

    float sum = 0.0f;
    for (int j = 0; j < items_per_thread; ++j)
    {
        const size_t idx = base + tid
                         + static_cast<size_t>(j) * blockDim.x;
        if (idx < n)
            sum += in[idx];
    }

    s[tid] = sum;
    __syncthreads();

    for (unsigned int stride = blockDim.x >> 1;
         stride > 0; stride >>= 1)
    {
        if (tid < stride)
            s[tid] += s[tid + stride];
        if (stride > 1)
            __syncthreads();
    }

    if (tid == 0)
        partial[blockIdx.x] = s[0];
}

保留了用户基础版最后一轮省略屏障的方式。stride=1 时仅线程 0 更新并读取 s[0]，不存在等待其他线程写入的需求。其他轮次仍由全部线程执行屏障。

测量前的预测

第一轮完整 block 数约减为原来的 1/I；每个 block 的树深度不变，原始输入总量不变，不能据此预测 I 倍提速。I 不是越大越好；每线程串行工作增加和 grid 缩小都可能影响性能。I=1 可作为与基础版对照的配置，但两个不同 kernel 的编译结果和耗时不保证完全一致。
